# 🖥️ CPU Monitor Project (Python)

A real-time CPU monitoring tool built using Python.  
It tracks system performance and displays CPU usage in a simple and efficient way.

---

## 📌 Features

- 📊 Real-time CPU usage monitoring  
- ⚡ Lightweight and fast execution  
- 🧠 Simple Python-based logic  
- 📈 Can be extended for system analytics dashboards  
- 💻 Works on Windows, Linux, and macOS  

---

## 🛠️ Tech Stack

- Python 🐍  
- psutil library  
- Jupyter Notebook (for testing/analysis)
